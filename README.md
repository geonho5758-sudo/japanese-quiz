# 絵でクイズ — 일본어 그림퀴즈

일본어스터디 5주년 파티용 팀전 퀴즈 게임
빔프로젝터에 띄우고 진행자가 키보드로 조작합니다

## 파일 구성

```
index.html      게임 본체 (건드릴 일 거의 없음)
questions.js    문제 데이터 ← 여기만 편집하면 됩니다
images/         제미나이로 만든 그림 넣는 곳
```

## 문제 추가하기

`questions.js` 를 열어서 아래 형식으로 추가하면 끝입니다

```js
{
  id: "b4",
  level: "초급",              // 초급 / 중급 / 상급
  image: "images/neko.png",   // 그림 없으면 null
  word: "ねこ",
  reading: "neko",
  meaning: "고양이",
  hints: ["2글자", "ね로 시작", "야옹"]
},
```

- `level` 값이 문제표의 탭을 나눕니다
- `hints` 는 최대 3개, 스페이스바로 하나씩 공개됩니다
- 그림은 `images/` 폴더에 넣고 경로를 적어주세요

## 조작법

| 키 | 동작 |
|---|---|
| `P` | 문제표 열기 / 닫기 |
| `Space` | 힌트 1 → 2 → 3 → 정답 |
| `Enter` | 힌트 건너뛰고 바로 정답 |
| `→` | 다음 문제 |
| `1` / `2` | 각 팀 +1점 |
| `Shift`+`1` / `2` | 각 팀 −1점 |

## GitHub Pages 배포

1. 깃허브에서 새 저장소 만들기 (Public)
2. 이 폴더의 파일 3개 + `images/` 폴더를 업로드
3. 저장소 → Settings → Pages
4. Source 를 `Deploy from a branch`, 브랜치를 `main` / `(root)` 로 지정 후 Save
5. 1~2분 뒤 `https://아이디.github.io/저장소이름/` 으로 접속됩니다

파티 당일엔 이 주소를 노트북에서 열고 `F11` 로 전체화면 하면 됩니다

## 미리 확인하려면

파일을 그냥 더블클릭해도 열리지만, 이미지가 안 뜰 수 있어요
폴더에서 터미널 열고 아래 명령어를 치면 안전합니다

```
python3 -m http.server 8000
```

그 다음 브라우저에서 `http://localhost:8000` 접속
